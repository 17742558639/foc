# FOC电机疯狂抖动排查记录（小白版）

## 1. 先看结论

最初的现象是：电机剧烈来回抖动，VOFA显示机械速度不断正、负、正、负切换。

这不是编译错误。真正的问题是代码里的“方向”和“角度零点”没有与实际电机、编码器和相序统一：

1. 编码器原始计数方向与希望的机械正方向相反。
2. 电角度方向和旧的电角度偏移不适用于当前实物。
3. dq坐标系中的正`iq`产生逆时针转矩，但项目希望顺时针为正。
4. 参数错误时仍给较大电流，电机被正反转矩反复拉扯，所以疯狂抖动。

经过逐项低功率验证后，电机已能稳定转动，不再正负来回抖动。

当前项目统一规定：

- 顺时针机械运动为正方向。
- 外部正`iq`命令表示顺时针正转矩。
- VOFA机械速度`I6 > 0`表示顺时针。

## 2. 当前已经验证的参数

以下参数已经通过手转、静态标定和低电流运行验证：

```c
#define ENC_COUNTS_PER_REV 8192.0f
#define ENC_DIR            (-1.0f)
#define ENC_ELEC_DIR       (-1.0f)
#define ENC_ELEC_OFFSET    4.7093f
#define FOC_POLE_PAIRS     10
#define FOC_TORQUE_SIGN    (-1.0f)
```

当前仍处于低风险测试配置：

```c
#define TARGET_IQ           0.2f
#define FOC_UQ_LIMIT        0.60f
#define FOC_CURRENT_I_LIMIT 0.30f
```

不要急着恢复高电流和高电压限幅。电流采样比例还没有完成实物校准。

## 3. 用最简单的话理解FOC

### 3.1 机械角是什么

机械角就是电机轴真实转过的角度：

- 一整圈等于`360°`。
- 用弧度表示时，一整圈等于`2π`，约`6.283rad`。
- 本项目规定顺时针转动时机械角增加。

### 3.2 电角度是什么

电机内部有多对磁极。当前电机是10极对，所以机械轴转一圈，电角度会循环10圈。

FOC必须随时知道转子磁场的方向。如果电角度方向或零点错误，控制器以为自己在向前推，实际可能正在侧推或反推。

### 3.3 `id`和`iq`是什么

可以先这样理解：

- `id`：吸磁方向的电流。表贴式永磁电机正常运行时通常希望接近`0A`。
- `iq`：主要产生转矩的电流。它决定电机往哪个方向用多大力。

正确换相时，给`iq`后应看到：

- `iq`有稳定的目标和反馈。
- `id`接近`0A`。
- 电机持续向同一个方向出力。

如果电角度错误，`id/iq`会互相串扰，转矩方向还可能随转子位置变化，表现就是抖动、尖叫和速度正负跳变。

### 3.4 偏移量是什么

编码器的机械零点不一定等于转子磁极的电气零点，所以需要`ENC_ELEC_OFFSET`把两者对齐。

本项目通过静态标定获得4次结果：

```text
4.709325
4.709325
4.603400
4.769100
```

采用中位数附近的：

```c
#define ENC_ELEC_OFFSET 4.7093f
```

## 4. 实际排查过程

### 第一步：把电流降到零

先把`TARGET_IQ`设为`0A`，避免参数错误时继续用大电流拉扯电机。

原则：方向、角度、采样没有确认前，不能直接用`3A`测试。

### 第二步：只读编码器

设置：

```c
#define ENC_TEST_MODE 1
```

这个模式不启动PWM，电机可以自由手转。

实测结果：

- I3起始约`8193`。
- 电机轴转一机械圈后，I3约`16207`。
- 增量约`8014`，接近`8192`。
- 转`90°、180°、360°`时，机械角显示都能正确对应。

因此本项目采用：

```c
#define ENC_COUNTS_PER_REV 8192.0f
```

注意：MT6701标称14位范围是`0~16383`，但当前实物的电机轴转一圈实测约增加8192计数。调试时以实测机械关系为准，不能只看芯片标称值。

### 第三步：统一机械正方向

实测顺时针手转时，传感器原始计数递减。项目希望顺时针为正，因此设置：

```c
#define ENC_DIR (-1.0f)
```

修改后小角度验证：顺时针转`10°~20°`，机械角增加，方向正确。

### 第四步：静态标定电角度零点

设置：

```c
#define ENC_TEST_MODE 2
```

程序使用低电压固定矢量吸住转子，VOFA的`I4`给出建议偏移。多次重复标定后采用`4.7093rad`。

### 第五步：用小电流验证转矩方向

先给内部`+0.2A iq`，电机稳定逆时针，速度为负。

再给内部`-0.2A iq`，电机稳定顺时针，速度为正。

实测说明：dq内部负`iq`才对应项目规定的顺时针正方向。

因此在电流环入口加入：

```c
target_iq_control = FOC_TORQUE_SIGN * target_iq;
```

并设置：

```c
#define FOC_TORQUE_SIGN (-1.0f)
```

这样外部仍然可以使用直观约定：外部`+0.2A`表示顺时针，内部自动转换为`-0.2A`进行控制。

### 第六步：最终低电流验证

外部命令恢复为`+0.2A`后，实测：

```text
内部iq参考 I0 ≈ -0.200A
环内iq反馈 I1 ≈ -0.100A
id反馈     I2 ≈ +0.013A
q轴电压   I3 ≈ -0.312V
交叉iq    I5 ≈ -0.104A
机械速度   I6 ≈ +26.57rad/s
```

判断：

- `I6 > 0`，电机稳定顺时针。
- `I1`与`I5`接近，两套电流计算一致。
- `I2`接近零，电角度对齐基本正确。
- 速度不再正负来回跳，原抖动问题解决。

## 5. 当前VOFA通道说明

在`CURRENT_TEST_MODE=1`时：

| 通道 | 含义 | 当前怎么看 |
|---|---|---|
| `I0` | PI内部`iq`参考 | 外部正命令会经过方向转换，所以当前显示负值正常 |
| `I1` | 电流环测得的`iq` | 应与`I0`方向一致，并逐渐接近目标 |
| `I2` | 电流环测得的`id` | 正常应接近`0A` |
| `I3` | `vq`输出电压 | 不应长期顶住正负限幅 |
| `I4` | 机械角，单位度 | `0°/360°`回绕会形成竖直跳线，这是正常显示 |
| `I5` | 主循环独立计算的`iq` | 应与`I1`基本一致 |
| `I6` | 机械速度，单位rad/s | 正值为顺时针，负值为逆时针 |

## 6. 为什么轻推一下才启动

`0.2A`是故意使用的低电流测试值，启动转矩可能不足以克服：

- 轴承和负载静摩擦；
- 电机齿槽转矩；
- 驱动芯片和功率管的电压死区；
- 当前临时设置的`0.60V`电压限幅；
- 当前临时设置的`0.30V`积分限幅。

所以“静止时不启动，轻推后可以稳定转”不等于方向错误。它说明方向已基本正确，但启动转矩不足。

不要直接通过大幅提高电流来解决。应先校准电流采样，再逐步增加。

## 7. 还没有完成的工作：电流校准

当前代码为：

```c
#define CURRENT_AMP_PRE_CONST 0.000806f
```

这个系数是否正确取决于三项硬件参数：

1. STM32 ADC参考电压。
2. 分流电阻阻值。
3. INA240具体增益型号。

计算公式：

```text
每个ADC计数对应的电流
= ADC参考电压 / 4095 / 分流电阻 / 放大器增益
```

常见组合：

| ADC参考电压 | 分流电阻 | 放大器增益 | 正确系数 |
|---:|---:|---:|---:|
| 3.3V | 0.01Ω | 50 | 0.001612 A/count |
| 3.3V | 0.01Ω | 100 | 0.000806 A/count |
| 3.3V | 0.02Ω | 50 | 0.000806 A/count |

因此`0.000806`不一定错误。必须先确认：

- INA240是A1、A2、A3还是A4；
- 分流电阻丝印是`R005`、`R010`、`R020`还是其他；
- MCU的VDDA/VREF+实测电压。

在这些数据确认前，不要把电流提高到`1A`、`2A`或`3A`。

## 8. 后续正确调试顺序

1. 确认INA240完整型号和增益。
2. 确认分流电阻阻值。
3. 测量STM32的VDDA/VREF+。
4. 计算并修改`CURRENT_AMP_PRE_CONST`。
5. 使用已知电流或电流表验证VOFA显示值。
6. 依次测试`0A → 0.2A → 0.5A`，每次短时间观察温升和波形。
7. 电流环稳定后再启用速度环。
8. 速度环稳定后再启用位置环或三环串级。

调试顺序必须是：

```text
编码器 → 电角度 → 电流采样 → 电流环 → 速度环 → 位置环
```

不能跳过内环，直接调外环。

## 9. 常见现象对照表

| 现象 | 优先检查 |
|---|---|
| 电机疯狂正反抖动 | 电角度方向、偏移、极对数、相序 |
| 速度持续正负切换 | 先判断电机是否真的来回转，不要只调速度PI |
| `id`很大、`iq`很小 | 电角度偏移或Park变换方向可能错误 |
| 正`iq`却反转 | `FOC_TORQUE_SIGN`或方向约定不一致 |
| 静止不启动，轻推后正常 | 启动转矩不足、静摩擦、死区或限幅太低 |
| `I4`出现0°/360°竖线 | 机械角正常回绕，不是编码器跳变 |
| `I1`与`I5`差很多 | 电流读取时刻、并发读取或变换公式需要检查 |
| 电压长期顶住限幅 | 电流目标过高、采样比例错误、母线电压不足或积分饱和 |
| 编码器偶发全0或全1 | SPI通信、接线、供电或错误值处理需要检查 |

## 10. 安全注意事项

- 第一次测试新方向时只给小电流、短时间运行。
- 纯电流环没有速度限制，空载后会持续加速，不能长时间通电。
- 电机尖叫、剧烈抖动、突然高速转动或驱动板快速发热时立即断电。
- 不要在电机高速运行时徒手抓轴。
- 静态标定时不要强行扭动被吸住的转子。
- 每次只改一个方向参数，改完先做小角度或短时间验证。
- 实测结果优先于注释和理论推测。

## 12. 一句话记忆

FOC调试不要一上来调PID。先确认“一圈是多少、正方向是哪边、电角度零点在哪、电流到底是多少”，然后从小电流开始逐层闭环。
