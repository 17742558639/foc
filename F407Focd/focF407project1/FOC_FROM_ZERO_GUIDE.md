## 1. FOC到底在做什么

### 1.1 最直观的理解

三相永磁同步电机的转子上有永久磁铁。定子三相绕组通电后，也会产生一个磁场。

FOC的核心任务只有一句话：

> 随时知道转子磁铁朝向，并让定子磁场保持在最适合产生转矩的方向。

如果定子磁场方向正确，电机会持续朝一个方向转。如果方向错误，电机会出现：

- 只吸住，不旋转；
- 左右抖动；
- 转过一小段后卡住；
- 正反方向反复切换；
- 电流很大，但有效转矩很小。

因此，FOC调试最先确认的不是PID，而是角度、方向、极对数和电流采样。

### 1.2 为什么不能直接控制三相电流

电机转动时，A、B、C三相电流都是不断变化的交流量。直接对三条波形分别做PID，理解和调试都很困难。

FOC通过两次坐标变换，把三相交流量转换成两个接近直流的量：

```text
三相电流 ia、ib、ic
       |
       | Clarke变换
       v
静止坐标 i_alpha、i_beta
       |
       | Park变换，需要转子电角度
       v
旋转坐标 id、iq
```

转换后，可以把电流分成两个独立方向：

| 量 | 初学者理解 | 表贴式PMSM常用目标 |
|---|---|---:|
| `id` | 朝着转子磁铁方向的电流，主要表现为吸磁 | `0A` |
| `iq` | 垂直于转子磁铁方向的电流，主要产生转矩 | 由外环决定 |

可以暂时记住：

```text
id控制“吸多少”
iq控制“推多大力”
```

当前项目是表贴式永磁电机，所以正常运行时使用：

```c
#define FOC_ID_TARGET 0.0f
```

### 1.3 Clarke变换做什么

三相电流满足近似关系：

```text
ia + ib + ic = 0
```

所以三相中只有两个独立变量。Clarke变换把三相量压缩到固定不动的二维平面：

```text
ia、ib、ic -> i_alpha、i_beta
```

当前工程的主要计算为：

```c
current_alpha = current_a;
current_beta  = (current_a + 2.0f * current_b) * 0.57735f;
```

这里的`0.57735`约等于`1/sqrt(3)`。

### 1.4 Park变换做什么

Clarke坐标系固定在定子上，但转子一直在转。Park变换根据转子电角度，把固定坐标系跟着转子一起旋转：

```text
i_alpha、i_beta + 电角度 -> id、iq
```

当前工程使用：

```c
current_d =  current_alpha * cos_a + current_beta * sin_a;
current_q = -current_alpha * sin_a + current_beta * cos_a;
```

如果电角度正确，稳定运行时`id`、`iq`是比较平稳的直流量，PI控制器容易控制。

如果电角度错误，真实的`id`和`iq`会混在一起。即使VOFA上看见“iq跟随目标”，也可能只是使用了同一个错误坐标计算出来的结果，电机实际未获得持续转矩。因此必须先做开环动态验证。

### 1.5 电流PI做什么

电流环比较目标电流和实测电流：

```text
id误差 = id目标 - id实测
iq误差 = iq目标 - iq实测
```

两个PI分别生成电压命令：

```text
id误差 -> d轴PI -> vd
iq误差 -> q轴PI -> vq
```

当前工程的参数是：

```c
#define FOC_CURRENT_KP 0.12f
#define FOC_CURRENT_KI 12.0f
```

`Kp`负责立即响应，`Ki`负责逐渐消除长期误差。积分必须限幅，否则电机堵转时积分会持续累积，松开后突然输出过大。

### 1.6 反Park、反Clarke和SVPWM做什么

PI得到的是`vd`、`vq`，功率板需要的是三相PWM占空比，因此还要反向变换：

```text
vd、vq
  -> 反Park
u_alpha、u_beta
  -> 反Clarke
ua、ub、uc
  -> SVPWM公共模式注入
A、B、C三相占空比
```

当前工程在`foc_output_dq()`中完成这些工作，并把结果写入TIM1的三个比较寄存器。

占空比都在`0.5`附近变化是正常现象。三相都恰好为`0.5`时，三相线电压互相抵消，电机基本不出力。

## 2. 机械角与电角度

### 2.1 机械角

机械角就是肉眼看到的电机轴角度：

```text
一机械圈 = 360度 = 2pi rad
```

当前项目规定：

```text
从指定观察方向看，顺时针为机械正方向
```

因此编码器原始计数方向与项目规定相反时，需要使用：

```c
#define ENC_DIR (-1.0f)
```

### 2.2 电角度

电机可能有多对磁极。转子机械转一圈时，电气状态会重复多次：

```text
电角度 = 机械角 x 极对数 + 电角度偏移
```

当前电机使用10极对：

```c
#define FOC_POLE_PAIRS 10
```

因此机械轴转一圈，电角度循环10圈。机械角只错一点点，乘以10后就会成为明显的电角度误差。

当前闭环代码实际使用：

```c
angle = angle_mech * FOC_POLE_PAIRS * ENC_ELEC_DIR
      + ENC_ELEC_OFFSET;
```

三个参数各自负责不同问题：

| 参数 | 作用 | 错误表现 |
|---|---|---|
| `FOC_POLE_PAIRS` | 机械角到电角度的倍率 | 某些位置能转，转一段后失步或卡住 |
| `ENC_ELEC_DIR` | 电角度随机械角变化的方向 | 静止点可能正确，一转动就越来越错 |
| `ENC_ELEC_OFFSET` | 编码器零点与转子磁极零点的差 | 整体侧推、吸住、转矩小、`id/iq`串扰 |

### 2.3 静态标定为什么不够

静态标定能找到某一个机械位置上的电角度偏移，但不能单独证明以下两项正确：

- 电角度变化方向正确；
- 极对数正确。

所以静态标定之后还必须进行低压开环动态验证。开环旋转磁场能带着转子连续同步转动，并且动态反推偏移基本保持不变，才说明“方向、倍率、偏移”整体基本正确。

## 3. 三层闭环如何套在一起

### 3.1 电流环：控制力矩

电流环是最内层，也是最快的一层：

```text
目标iq -> 电流PI -> vq -> PWM -> 电机 -> 实测iq
```

外部给正`iq`，当前项目约定为顺时针正转矩。由于实际相序和dq定义的关系，代码内部通过：

```c
#define FOC_TORQUE_SIGN (-1.0f)
```

把外部正命令转换为内部负`iq`参考。这只是坐标约定，不表示控制错误。

固定`iq`相当于一直用同样的力推电机，不会主动限制速度。空载时可能持续加速，因此固定电流测试必须很短。

### 3.2 速度环：决定需要多大力

速度环套在电流环外面：

```text
目标速度 - 实测速度
        -> 速度控制器
        -> iq目标
        -> 电流环
```

速度低于目标时，速度环给正转矩；速度高于目标时，速度环减小转矩，必要时给反向制动力。

因此，速度环的输出不是电压，而是`iq`目标。这样速度环只负责决定“需要多大力”，电流环负责把这个力快速做出来。

### 3.3 位置环：决定应该跑多快

位置环再套在速度环外面：

```text
目标位置 - 实际位置
        -> 位置控制器
        -> 目标速度
        -> 速度环
        -> iq目标
        -> 电流环
```

离目标很远时，位置环给较大的目标速度；接近目标时，目标速度逐渐降低；到达目标附近后停止。

### 3.4 为什么一定要从内到外调

三层环的关系是：

```text
位置环依赖速度环正确
速度环依赖电流环正确
电流环依赖角度和电流采样正确
```

如果电流环还不稳定就调速度环，速度环会不断改变错误的电流目标；如果速度环还不稳定就调位置环，位置环会进一步放大问题。

正确顺序必须是：

```text
电流环通过 -> 再开速度环 -> 速度环通过 -> 再开位置环
```

## 4. 当前工程每50us发生什么

TIM1以20kHz产生更新中断，即每`50us`执行一次控制。入口是：

```c
HAL_TIM_PeriodElapsedCallback()
```

在电流闭环模式中，一次完整控制周期为：

```text
1. encoder_update()
   读取MT6701
   -> 原始计数
   -> 机械角
   -> 机械速度

2. 计算电角度
   机械角 x 极对数 x 电角度方向 + 偏移

3. current_read()
   读取两相ADC
   -> 减去零漂
   -> 换算为安培
   -> 重建第三相电流

4. Clarke变换
   ia、ib、ic -> i_alpha、i_beta

5. Park变换
   i_alpha、i_beta + 电角度 -> id、iq

6. 电流PI
   id误差 -> vd
   iq误差 -> vq

7. 电压矢量限幅
   sqrt(vd^2 + vq^2)不能超过安全上限

8. 反Park和三相电压计算
   vd、vq -> ua、ub、uc

9. SVPWM公共模式注入
   ua、ub、uc -> 三相占空比

10. 写入TIM1比较寄存器
    功率板输出新的三相PWM
```

这套流程每秒重复20000次。

注意：`encoder_update()`在一个控制周期中只能调用一次。重复调用会让第二次角度差接近零，导致速度估算错误。

## 7. 从零开始：第一次上电前

### 7.1 准备工具

至少准备：

- 可限流直流电源；
- 万用表；
- ST-Link和Keil；
- VOFA+；
- 电机、驱动板、编码器；
- 能随时断开主电源的开关。

初次调试不要直接使用大功率电池。可限流电源在接线或程序错误时更容易保护功率板。

### 7.2 断电检查清单

在没有接通电机主电源时逐项确认：

1. 三相线接到驱动板的A、B、C输出，线头之间没有短路。
2. 编码器供电电压符合模块要求，电源和地没有接反。
3. MCU地、驱动板逻辑地、编码器地共地。
4. 编码器SPI片选、时钟和数据线与代码引脚一致。
5. 电机轴可以手动转动，没有明显机械卡死。
6. 功率板附近没有松动螺丝、焊锡或裸线。
7. 第一次上电时电机保持空载。

### 7.3 电源限流建议

第一次验证逻辑和PWM时，把电源电流限制设得较低。只有在确认三相PWM、编码器和电流采样正常后，才逐步提高限流值。

不要把软件限流当作唯一保护。软件可能因为角度、ADC比例或中断错误而失效，台式电源限流是独立保护层。

### 7.4 第一条安全原则

出现以下任一现象立即断开主电源：

- 电机剧烈正反抖动；
- 电机或驱动板尖叫；
- 电机突然高速运行；
- MOS管、电机或采样电阻快速发热；
- 电源持续限流；
- VOFA显示电流远超命令值；
- 编码器数值大量跳变或全0、全1。

断电后记录现象，一次只改一个参数，不要同时改方向、偏移、极对数和PI。

## 8. 第一道关：PWM零输出

### 8.1 目标

先证明MCU、定时器和驱动板能够工作，并且“零命令”不会让电机出力。

### 8.2 应有状态

三相PWM都启动，但三相占空比都设为约`50%`：

```c
__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, 2100);
__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_2, 2100);
__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_3, 2100);
```

当前`ARR=4199`，所以比较值约2100对应50%。三相占空比相同，线电压互相抵消，电机应基本不出力。

### 8.3 操作

1. 暂时禁止所有开环和闭环输出。
2. 编译并烧录。
3. 接通逻辑电源，再接通受限流保护的主电源。
4. 测试不超过数秒。
5. 观察电机是否静止、驱动板是否异常发热。

### 8.4 通过标准

- 电机不主动转动；
- 三相占空比接近0.5；
- 电源没有明显异常电流；
- 驱动板不快速发热。

如果三相相同占空比时电机仍强烈出力，应先查驱动板输入极性、PWM通道映射和硬件接线，不进入编码器和FOC调试。

## 9. 第二道关：只读编码器

### 9.1 目标

在完全不驱动电机的条件下，确认编码器读数稳定、一圈计数正确、方向定义正确。

### 9.2 当前工程模式

在`Core/Src/main.c`中设置：

```c
#define ENC_TEST_MODE 1
```

只读模式不启动PWM，电机可以自由手转。

### 9.3 先看静止稳定性

电机轴保持不动，观察原始计数：

- 允许末位有少量跳动；
- 不应在相距很远的数值之间跳变；
- 不应频繁出现0或65535；
- `error_count`不应快速增加。

如果静止读数不稳定，优先检查SPI模式、片选时序、供电、地线和磁铁安装，不要用软件滤波掩盖通信故障。

### 9.4 测一机械圈计数

1. 在电机轴和外壳上各做一个对齐标记。
2. 记录起始计数。
3. 缓慢手转整整一机械圈，让标记重新对齐。
4. 记录结束计数。
5. 处理计数回绕后计算差值。

当前实物测得约8192计数/机械圈，因此项目使用：

```c
#define ENC_COUNTS_PER_REV 8192.0f
```

不要只根据“MT6701是14位”就直接填16384。芯片输出格式、机械传动或当前读取位可能使实测关系不同，控制算法必须先与实物一致。

### 9.5 验证机械方向

当前项目规定顺时针为正。先只转`10度到20度`，不要一开始转整圈。

通过标准：

- 顺时针小角度转动时，机械角增加；
- 逆时针小角度转动时，机械角减小；
- 经过0度和360度时允许正常回绕。

当前实物顺时针时原始计数递减，因此使用：

```c
#define ENC_DIR (-1.0f)
```

机械方向参数改变后，原来的电角度偏移通常不能继续使用，必须重新标定。

## 10. 第三道关：确认电机极对数

### 10.1 极对数为什么重要

极对数决定机械角变化多少时，电角度应该变化多少：

```text
机械转一圈，电角度转“极对数”圈
```

极对数填错时，某一个静止位置仍可能表现正常，但转动后电角度误差会不断积累，电机常表现为转一小段就卡住或抖动。

### 10.2 获取方法

优先级从高到低：

1. 电机厂家数据表明确给出的极对数；
2. 厂家给出磁极数时，极对数等于磁极数除以2；
3. 使用低压旋转磁场和编码器，测量一机械圈内电气状态重复次数；
4. 使用示波器或反电动势测量辅助确认。

不要把“槽数”直接当成极对数。定子槽数和转子磁极数不是同一个参数。

### 10.3 当前项目

当前配置为：

```c
#define FOC_POLE_PAIRS 10
#define ENC_POLE_PAIRS 10
```

两个宏必须一致。当前低压开环动态实测支持10极对配置。

## 11. 第四道关：静态电角度偏移标定

### 11.1 标定目标

编码器的0度不一定等于转子磁铁的电气0度。`ENC_ELEC_OFFSET`负责补偿两者差值。

### 11.2 当前工程模式

设置：

```c
#define ENC_TEST_MODE 2
```

程序用低电压固定矢量吸住转子。转子停稳后，VOFA给出建议偏移。

### 11.3 操作顺序

1. 电机空载，确保可以随时断电。
2. 烧录静态标定固件。
3. 上电后不要用手强行扭转被吸住的电机轴。
4. 等待约0.5秒到1秒，让转子稳定。
5. 读取VOFA建议偏移。
6. 断电。
7. 手动改变起始机械位置，重复至少4次。
8. 选择重复性较好的中位数附近值。

当前项目四次结果为：

```text
4.709325
4.709325
4.603400
4.769100
```

采用：

```c
#define ENC_ELEC_OFFSET 4.7093f
```

### 11.4 通过标准

- 每次标定结果集中在相近范围；
- 电机能被稳定吸住，不剧烈抖动；
- 改变起始机械位置后，建议偏移仍基本一致。

如果多次结果差异很大，先检查标定期间是否有其他控制环同时运行、编码器是否稳定、预定位电压是否足够。不要直接取平均值掩盖异常。

## 12. 第五道关：低压开环动态验证

### 12.1 为什么必须做

静态标定只证明一个位置上的偏移可能正确。低压开环用于同时验证：

- 三相PWM和相序能形成旋转磁场；
- 转子能否跟随旋转磁场；
- 极对数是否基本正确；
- 电角度变化方向是否基本正确；
- 编码器速度方向是否与项目约定一致。

### 12.2 当前工程配置

开环时关闭各闭环开关：

```c
#define USE_CASCADE_LOOP      0
#define USE_SPEED_CURRENT_LOOP 0
#define USE_CURRENT_LOOP      0
#define USE_SPEED_LOOP        0
#define USE_POSITION_LOOP     0
```

中断最终调用：

```c
foc_open(g_target_speed);
```

使用较低目标速度：

```c
#define TARGET_SPEED 3.0f
```

当前已验证的低速开环补偿为：

```c
#define FOC_VOLT_OFFSET 0.200f
```

在`3rad/s`机械目标、10极对时，开环输出约：

```text
0.200 + 0.0011 x 30 = 0.233V
```

### 12.3 VOFA通道

| 通道 | 含义 | 通过时的表现 |
|---|---|---|
| `I0` | 开环目标机械速度 | 最终到目标值 |
| `I1` | 编码器实测机械速度 | 大小接近目标；符号按方向约定判断 |
| `I2` | 动态反推电角度偏移 | 基本保持在固定范围，0/6.28回绕允许跳线 |
| `I3` | 开环输出电压 | 与V/f计算一致，不超过安全限幅 |
| `I4` | A相占空比 | 在0.5附近周期变化 |
| `I5` | B相占空比 | 在0.5附近周期变化 |
| `I6` | C相占空比 | 在0.5附近周期变化 |

### 12.4 操作顺序

1. 电机保持空载。
2. 第一次只给很低电压，短测2秒到3秒。
3. 如果转子仅左右摆动，断电后小幅提高开环补偿电压。
4. 每次只调整电压，不同时改速度、方向和极对数。
5. 转子能够连续跟随后，记录方向、实测速度和动态偏移。

### 12.5 当前实测过程

`0.083V`时，转子只左右摆动，说明电压不足以克服齿槽转矩和静摩擦。把总输出提高到约`0.233V`后，电机连续同步旋转，实测速度大小约`3rad/s`，动态偏移基本稳定。

这证明：

- 功率输出链路能够形成旋转磁场；
- 转子能够同步跟随；
- 10极对配置基本正确；
- 动态电角度关系基本正确。

### 12.6 开环方向与闭环方向不要混淆

开环正速度对应哪个物理方向，取决于三相相序和开环角度累加方向。编码器机械正方向则是项目人为定义。

因此，发现开环`+3rad/s`实际逆时针时，不要立即修改`ENC_DIR`。应先分别记录：

- 磁场的物理旋转方向；
- 编码器测得的速度符号；
- 项目希望定义的机械正方向。

闭环中再通过明确的方向参数统一约定。方向类修改必须先用小角度或短时间验证。

## 13. 进入电流环前的关卡检查

只有下面全部为“是”，才进入电流采样和电流环：

- [ ] 三相50%占空比时电机不异常出力。
- [ ] 编码器静止读数稳定。
- [ ] 手转一机械圈计数已实测。
- [ ] 顺时针和逆时针的小角度方向已验证。
- [ ] 极对数有数据或动态实测依据。
- [ ] 静态偏移重复标定结果基本一致。
- [ ] 低压开环能够连续同步旋转。
- [ ] 开环实测速度大小与目标大致对应。
- [ ] 动态反推偏移没有持续转圈漂移。
- [ ] 驱动板和电机没有异常发热。

任意一项未通过，都不要靠增大电流或调PID强行进入闭环。
