# PMSMfoc — STM32F407 磁场定向控制（FOC）实战工程

> 从**开环 V/f** 一路做到**位置闭环 / 速度闭环**的完整代码与调试记录。
> 板子：FK407M3-VET6（STM32F407VET6） + SimpleFOCShield V2.0.4（L6234）
> 电机：ProDrone 3505 类小云台电机（实测 0.36 Ω/相、**21 对极**）
> 编码器：MT6701（14 位绝对式，SPI/SSI）

---

## 1. 这个仓库是什么

一套**手写、可读、逐步可验证**的 FOC 实现，不是库的调用示例。

设计原则（贯穿全部代码）：

- 变量名写全，不缩写
- 一个函数从上往下读，不跳转
- 每一步都能单独看懂，注释写清"为什么"

包含三层控制 + 五个调试模式，全部可以在 VOFA+ 上直接观察。

## 2. 硬件接线

### 2.1 MCU → 驱动板（SimpleFOCShield / L6234）

| STM32F407 | 驱动板 | 说明 |
|---|---|---|
| **PE9**（TIM1_CH1） | IN1 / PWM A | |
| **PE11**（TIM1_CH2） | IN2 / PWM B | |
| **PE13**（TIM1_CH3） | IN3 / PWM C | |
| GND | GND | **必须共地** |
| 3.3V | EN1/EN2/EN3 | 使能（三个并一起） |

> ⚠️ L6234 只需 **3 路单端 PWM**，上下桥互补和死区都在芯片内部做。
> **绝对不要接 CHxN**（PE8/PE10/PE12），会和驱动板打架。

### 2.2 编码器 MT6701（SPI/SSI，只读）

| MT6701 | STM32F407 | 说明 |
|---|---|---|
| VCC | 3.3V | |
| GND | GND | |
| **Z/CS** | **PA4** | 片选，普通 GPIO 输出 |
| **B/SCLK** | **PA5** | SPI1_SCK |
| **A/MISO** | **PA6** | SPI1_MISO |
| — | PA7 不接 | SSI 只读，不需要 MOSI |

**MODE 跳线必须跳到 VCC（SPI 模式），R4 焊盘保持断开。**

### 2.3 电源

```
12V 电源 ──┬──► 驱动板 TB_PWR (+/−)
           └──► 核心板
（共地即可；建议驱动板单独供电，核心板走 USB，避免大电流拖垮核心板稳压器）
```

## 4. 快速开始

### 4.1 编译烧录

```
1. 用 Keil MDK 打开 MDK-ARM/focF407project1.uvprojx
2. 确认 encoder.c 在 Core/Src 组里（CubeMX 重新生成后可能掉）
3. Build → Download
```

### 4.2 看波形

```
1. USB 线插板子，设备管理器确认 COM 口
2. VOFA+ → 数据引擎选 JustFloat → 串口 → 该 COM 口 → Δt = 5ms
3. 打开波形控件
```

> 注意：**一个串口同时只能被一个程序占用**。用 VOFA+ 时先关掉串口助手。

### 4.3 用串口助手看明文

```c

#define VOFA_USE_TEXT   1     // 1 = FireWater 文本，0 = JustFloat 二进制
#define VOFA_PERIOD_MS  50U   // 文本模式建议放慢，否则刷太快看不清
```

| `FOC_U_OFFSET` | 低速补偿电压（V） | `0.30` |

## 6. 三种控制模式

`main.c` 顶部两个开关：

```c
#define USE_SPEED_LOOP      1   // 速度闭环（L2）
#define USE_POSITION_LOOP   0   // 位置闭环（L1）
// 两个都是 0 → 开环 V/f
```

| 模式 | 输入 | 反馈 | 输出 |
|---|---|---|---|
| 开环 V/f | 目标转速 | 无 | 查表电压 |
| 位置环 | 目标角度 | 编码器角度 | PID → 电压 |
| 速度环 | 目标转速 | 编码器差分速度 | V/f 前馈 + PI → 电压 |

三者共用同一个输出级 `foc_output(theta, Uq)`：
反 Park → 反 Clarke → 共模注入（SVPWM）→ 占空比 → CCR。

## 7. 五个调试模式（`ENC_TEST_MODE`）

| 值 | 模式 | 用途 |
|---|---|---|
| `0` | 正常运行 | 按上面的控制开关跑 |
| `1` | 只读编码器 | 不启 PWM、不开中断，手转看角度 |
| `2` | 静态标定 | 固定电压矢量吸住转子，读 ch4 = 建议 offset |
| `3` | 升压扫描 | 电压 0.1→1.5V 慢升，找"启动电压" |
| `4` | offset 扫描 | offset 自动转一圈，看电机何时开始往目标走 |

## 8. 标定流程（换电机必做）

```
第 0 步  确认极对数（拆开数磁铁 ÷2，或查规格书）
第 1 步  ENC_TEST_MODE=1    手转一圈，确认角度 0→6.28 平滑
第 2 步  验证极对数是否正确：开环 1.0 rad/s，看实测/给定 ≈ 1.0
第 3 步  ENC_TEST_MODE=2    读 ch4 → 填进 ENC_ELEC_OFFSET
第 4 步  ENC_TEST_MODE=0 + 位置环，推一下轴看能否弹回
```

> ⚠️ 改 `FOC_POLE_PAIRS` 之后，**offset 必须重标**，且
> `FOC_TORQUE_SIGN` 要跟着检查（offset 差 π 时符号要翻）。

## 9. 踩过的坑（都写在代码注释里）

| 现象 | 根因 |
|---|---|
| PWM 只有 6.4 kHz | CubeMX 按 25 MHz 配晶振，板上是 8 MHz |
| 芯片非常烫 | V/f 参数按 10 Ω 电机写的，本机 0.36 Ω → 电流大 19 倍 |
| 编码器读不出 | SPI 分频 42 MHz 太快，改 16（5.25 MHz） |
| 位置环大电流零转矩 | 电角度 offset 差 90° |
| 能顶住但推开回不来 | **极对数填错**（7 → 10 → 21） |
| 电压给足仍不转 | 转矩 = Kt×I，Kt≈0.0099 N·m/A，静摩擦比它能拿出的还大 |

## 10. 当前状态与硬件限制

```
✅ 时钟 / PWM / SVPWM / 编码器 / 电角度标定  全部验证通过
✅ 位置闭环：能定位、能顶住
⚠️ 速度闭环：代码就绪，受转矩限制
❌ 带负载运行：做不到
```

**根因是硬件选型**：0.36 Ω 低阻电机要 2~3 A 才出转矩，而 L6234
在无散热片下持续电流只有 ~1.6 A。

实测温升地图（20 kHz，无散热）：

| Uq | 电流（估） | 芯片损耗 | 手感 |
|---|---|---|---|
| 0.7 V | 1.3 A | 1.5 W | 温 |
| 1.0 V | 1.85 A | 3.1 W | 烫但能摸 |
| **1.3 V** | **2.4 A** | **5.2 W** | **上限** |
| 2.0 V | 3.7 A | 12.3 W | 不可持续 |

**下一步**：换 5~15 Ω 云台电机（2208 / 2804 / 4108），
同样的控制代码只需重标极对数和 offset，即可放开限幅做电流环。
