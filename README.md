# PMSMfoc — STM32F407 手写磁场定向控制（FOC）

> **不依赖任何现成电机库**，从 Clarke/Park 变换一路写到三环串级（位置 → 速度 → 电流），
> 每一层都单独验证、单独给出实测数据。

| 项目 | 内容 |
|---|---|
| 主控 | FK407M3-VET6（STM32F407VET6，168 MHz） |
| 驱动板 | 灯哥开源 FOC V3 Plus（FD6288T + 分立 MOSFET + INA240 采样） |
| 电机 | 3505 类云台电机（0.36 Ω/相、**10 对极**、Kt ≈ 0.0099 N·m/A） |
| 编码器 | MT6701（14 位绝对式，SPI，每机械圈 **8192** 计数） |
| 开发环境 | Keil MDK + STM32CubeMX |

---

## 1. 实测结果

| 层 | 指标 | 备注 |
|---|---|---|
| **电流环** | 阶跃目标跟踪**相对误差 0.5%**（1.5 A 档） | id 稳在 ±0.01 A |
| | 零电流保持 iq = **0.0018 A** | 比编码器 1 个计数还小 |
| **速度环** | 目标 15 rad/s → 实测 **15.0024 rad/s**，稳态误差 **0.016%** | 带摩擦前馈 |
| **位置环** | 目标 300° → 可自动回到位，**约 ±5°** | 靠齿槽定位，见第 11 节 |

> 电流标度 `CURRENT_AMP_PRE_CONST` 属于**标定项**，换驱动板或改采样电路后需重新校准（方法见第 10 节）。

## 2. 控制架构

```
        目标角度
           │
           ▼
    ┌─────────────┐   位置误差  ┌──────────────┐
    │   位置环     │───────────►│  最低速度地板  │
    │  纯 P        │  v_cmd     │  + 一阶低通   │
    └─────────────┘            └──────┬───────┘
           ▲                          │ 速度指令
           │ 编码器机械角              ▼
           │                   ┌─────────────┐
           │                   │   速度环     │
           │                   │ 前馈 + PI    │
           │                   └──────┬──────┘
           │                          │ iq 指令
           │                          ▼
           │                   ┌─────────────┐
           │                   │   电流环     │
           │                   │  id/iq 双 PI │
           │                   └──────┬──────┘
           │                          │ Vd / Vq
           │                          ▼
           │                   ┌─────────────┐
           │                   │  SVPWM      │
           │                   │ 共模注入     │
           │                   └──────┬──────┘
           │                          ▼
           │                     TIM1 三相
           │                          │
           └────────── MT6701 ◄───────┘
                        ▲
                   ADC3 + DMA（硬件触发，只采两相）
```

**带宽分配**（外环必须比内环慢，否则两个控制器会互相追着跑）：

```
电流环 ~1 kHz  ←  1/20  ←  速度环 ~50 Hz  ←  1/10  ←  位置环 ~5 Hz
```

代码里四个单环 + 一个串级调度，互斥选择：

| 函数 | 反馈量 | 控制律 | 输出 |
|---|---|---|---|
| `foc_open()` | 无 | V/f 查表 | 电压 |
| `foc_close_position()` | 机械角 | 纯 P（Ki=Kd=0） | 电压 |
| `foc_close_speed()` | 转速 | V/f 前馈 + PI | 电压 |
| `foc_close_current()` | id / iq | 双 PI + 矢量限幅 | 电压 |
| **`cascade_position()`** | 角 + 转速 | **位置 P → 速度 PI → 电流** | 电压 |

前四个是「电压模式」，只有 `cascade_position()` 是真正的串级。

| MT6701 | STM32F407 | 说明 |
|---|---|---|
| VCC / GND | 3.3V / GND | |

## 6. 参数说明

参数分两类，**只有第一类是「结构性事实」，第二类会随调试变化**。

### 6.1 结构性参数（改之前先想清楚）

| 宏 | 值 | 说明 |
|---|---|---|
| `FOC_TS` | `0.00005` | 控制周期，20 kHz |
| `PWM_ARR` | `4199` | TIM1 中心对齐，PSC = 0，RCR = 1 |
| `VDC_BUS` | `12.0` | 母线电压（V） |
| **`FOC_POLE_PAIRS`** | **`10`** | 极对数（须与 `ENC_POLE_PAIRS` 一致） |
| `FOC_VOLTAGE_MAX` | `6.92` | SVPWM 物理上限 = Vdc/√3 |
| **`ENC_COUNTS_PER_REV`** | **`8192`** | 每机械圈有效计数 ⚠️ 见下 |
| `ENC_ANGLE_SHIFT` | `2` | 原始 16 位右移位数 |
| `ENC_SPEED_WINDOW` | `200` | 测速窗口（拍），10 ms |
| `ENC_JUMP_REJECT_RAD` | `0.020` | 跳变门槛 1.15° ⚠️ 见第 11 节 |

> ⚠️ **`ENC_COUNTS_PER_REV` 是最容易搞错的一个。**
> MT6701 是 14 位传感器，但原始字段（0~16383）要转**两整圈**才填满，
> 所以每机械圈实际只有 **8192** 个计数。
> 按 16384 算会让**所有角度和速度都只有真实值的一半**，而现象非常隐蔽：
> 角度平滑连续、不报错，只是闭环永远修不到位。
> **验证：转一整圈看角度是否走满 2π；或转 10 圈计时，与给定转速对照。**

### 6.2 整定参数（会随调试变化，以代码为准）

| 文件 | 宏 | 含义 |
|---|---|---|
| `foc.h` | `FOC_CURRENT_KP / KI / I_LIMIT` | 电流环 PI 与积分限幅 |
| `foc.h` | `FOC_UQ_LIMIT` | 矢量电压限幅（V） |
| `foc.h` | `FOC_IQ_LIMIT` | iq 指令限幅（A，真正的过流保护） |
| `cascade.h` | `CASCADE_POS_KP / DEADZONE / V_MIN` | 位置环比例、死区、最低速度地板 |
| `cascade.h` | `SPEED_TEST_FF / KP / KI / I_LIMIT / IQ_LIMIT` | 速度环前馈与 PI |
| `cascade.h` | `SPEED_BOOST_*`、`SPEED_BREAK_*` | 自适应起动参数 |

## 7. 控制模式（`main.c` 顶部开关）


## 8. 标定流程（换电机 / 换相序必做）

**顺序不能乱，前两步错了后面全白费。**

```
第 0 步  ENC_TEST_MODE=1，手转一整圈
         角度必须走满 0 → 6.283
         （只走 3.14 = 每圈计数填错了一倍）

第 1 步  开环 1.0 rad/s，实测转速应 ≈ 1.0
         也可用秒表法：转 10 圈计时，T 应 = 62.83 / 目标转速
         ← 这一步同时验完 极对数 / 编码器刻度 / 电角度公式

第 2 步  ENC_TEST_MODE=2，读建议 offset → 填进 ENC_ELEC_OFFSET
         断电重启复测，两次差 < 0.05 才可信

第 3 步  ★ 校验电角度方向
         开环转起来，用 offset_now = g_angle + π/2 − 极对数×机械角×方向
         反推：应是一条【恒定直线】。随转角扫描 → 方向反了，
         把 ENC_ELEC_DIR 改成 -1 并重标 offset

第 4 步  校验电流采样极性（环全关，开环只加固定 +vq）
         纯 q 轴电压应产生同号的 iq。测出反号 → CURRENT_SENSE_SIGN = -1

第 5 步  ENC_TEST_MODE=0 + 位置环，推一下轴看能否弹回
         往反方向跑 → FOC_TORQUE_SIGN 改成 -1
```

> ⚠️ **三个方向符号是配套的**：`ENC_ELEC_DIR`（电角度方向）、`FOC_TORQUE_SIGN`（转矩方向）、
> `CURRENT_SENSE_SIGN`（采样极性）。**改任何一个都要连带复查另外两个。**
> 改 `ENC_ELEC_DIR` 或换相序后，**offset 必须重标**。

## 9. 关键设计与为什么这么做

### 9.1 采样时序：纯硬件链，不靠软件轮询

低侧采样的致命约束：**只有下桥导通时分流电阻里才有电流**，而占空比越高这个窗口越窄。

```
TIM1 TRGO = Update（谷底 CNT=0）
   └─► 复位 TIM2（One Pulse + Trigger 模式，ARR = 3799）
          └─► TIM2 数满 3800 个计数 = 22.62 µs
                 └─► 此刻 TIM1 的 CNT 正好 = 3800（三相下桥全导通，窗口正中）
                        └─► TIM2 的 TRGO 触发 ADC3（两通道，15 周期）
                               └─► DMA2_Stream0 循环搬进 s_adc_dma[2]
```

**为什么不能用软件轮询**：轮询的采样相位会随中断响应抖动，会采到开关振铃；而且 ADC 的 `DR` 只有一个位置，第二次转换会覆盖第一次 —— 必须靠 DMA 立刻搬走。

**为什么采在 CNT=3800 而不是 4199（峰顶）**：ADC 转换要 2.57 µs，必须提前启动、让转换过程跨过峰顶。3800 对应「最大占空比 90%」的安全线。

### 9.2 SVPWM 用共模注入，不判扇区

```c
// foc_output_dq() 第 6 步
common = (max + min) / 2;   // 把三相占空比的中点拉回 0.5
```

与扇区判断法数学等价，但省掉全部判断和三角函数表。代价是相电压波形呈「马鞍形」—— 正常现象，线电压仍是纯正弦。

### 9.3 速度环用摩擦前馈，不用积分扛稳态

```
维持 15 rad/s 需要 0.146 A，而这一层最坏要 0.44 A
如果靠 P 项去修稳态误差 → P 会被放大 → 与齿槽纹波共振
```

所以：`iq = 摩擦前馈(0.0097 × 目标) + P×误差 + 积分`，**前馈扛稳态，P 只修残差**。

这个 0.0097 A/(rad/s) 是实测反推的：0.25 A 刚好维持 26 rad/s。

### 9.4 自适应起动：不猜起动电流

齿槽力矩**随转子位置变化**，固定的起动电流必然在某个位置不够、在另一个位置过猛。

```c
起始 0.05 A，每 0.5 ms 加 0.01 A，直到连续 200 拍 |speed| ≥ 0.5 rad/s
```

**起转之后积分必须归零** —— 起动要 0.44 A，维持只要 0.03 A，差 15 倍，继承起动电流必然超调。

### 9.5 位置环加「最低速度地板」

```
误差 1 rad  → v_cmd = 5 rad/s
误差 0.2 rad → v_cmd = 1 rad/s   ← 一定失速在齿槽峰上
```

所以速度指令不允许低于 `CASCADE_POS_V_MIN`，定位方式是「**以能跑的速度冲 + 进死区断电 + 靠齿槽停住**」。

## 10. 踩过的坑（最高价值的部分）

### 10.1 静默错误：不崩、不报错，只是所有数字悄悄错着

| 现象 | 根因 | 怎么查出来 |
|---|---|---|
| 能顶住但推开回不来 | **极对数填 21（实际 10）+ 每圈计数填 16384（实际 8192）** | 两个 2 倍误差乘积 ≈ 1.05，所有间接测量都自洽 —— 只有秒表量 10 圈这个**绝对参考**才破得开 |
| 位置环大电流零转矩 | 电角度 offset 差 90° | 电流明显、芯片发烫，但转子一动不动（矢量正好对着 d 轴） |
| 静止时符号对、转起来 iq 反号 | 对调电机线后**电角度方向**反了 | 静态预定位只能对齐一个点，验不出方向；要用「开环反推 offset 是否恒定」 |
| 电流环正反馈发散 | 采样极性反接 | 环全关，开环加 +vq，测出 −iq |

### 10.2 限幅链条：三次卡在同一个地方

**症状统一：目标追不上，但电压离限幅还很远。**

```
输出电压 = Kp × 误差 + 积分
0.06 × (1.5 − 0.99) + 0.300 = 0.331   ← 积分正好等于 I_LIMIT，顶死了
```

**排查法则：闭环「追不上但电压没顶限幅」→ 第一嫌疑是积分限幅。**
三层限幅必须层层递增，且都要大于目标所需：

```
FOC_CURRENT_I_LIMIT（积分） < FOC_UQ_LIMIT（矢量模）
且 UQ_LIMIT > 反电动势 + I×R
```

**转速越高反电动势越吃电压**：29 rad/s 时 EMF = 0.31 V，而 `I_LIMIT` 只有 0.30 V → iq 永远卡在 0.24 A，加目标完全无效。

### 10.3 其它真实踩过的坑

| 现象 | 根因 |
|---|---|
| PWM 只有 6.4 kHz | CubeMX 按 25 MHz 配晶振，板上是 8 MHz（比值 3.125 = 25/8） |
| 编码器读数恒 0 | CS 线（PA4）松动 —— SSI 靠 CS 下降沿启动 |
| 编码器完全读不出 | SPI 分频 42 MHz 太快，改 16（5.25 MHz） |
| 读取的电流明明很小 | 换算系数按手册算成 0.5 V/A，实测是 1.0 V/A（差 2 倍） |
| 电压给满电流上不去 | **死区压降**：低压小占空比时损失 0.5~0.9 V，等效阻抗从 0.33 Ω 看成 0.75 Ω |
| 「起动检测」总是误触发 | **2° 的编码器毛刺 → 3.5 rad/s 的假速度**（10 ms 窗口），骗过判据 |
| 电机嗡嗡抖但平均速度是 0 | 起动→超调→急刹 的极限环，切换时继承了起动电流 |
| 编译报「未声明」但函数明明有 | `Module/` 下的旧 `foc.h` 副本抢走了 `#include "foc.h"` |
| 标定值反复漂（5.26 → 4.40 → 4.03） | 中断里没给标定模式加空分支，速度环在抢控制权 |

## 11. 能力边界（诚实的部分）

**这台电机做不了低速连续运行，原因是物理的，不是代码的：**

```
齿槽峰（最坏位置）≈ 4.4 mN·m   ← 0.44 A 实测刚好越过
维持 15 rad/s 只需 ≈ 1.44 mN·m
维持  3 rad/s 只需 ≈ 0.29 mN·m

→ 低速时「过齿槽峰所需的转矩」远大于「维持转速所需的转矩」
→ 要么用大电流冲过去（然后一路加速到 26 rad/s），要么干脆过不去
→ 15 rad/s 能稳跑，是因为转子动能足够冲过齿槽峰
```

**这不是「没做成」，而是可量化的系统边界：**

| 转速 | 能否连续运行 | 原因 |
|---|---|---|
| 26 rad/s | ✅ 稳 | 动能充足，齿槽只是小坎 |
| 15 rad/s | ✅ 稳（实测 15.0024） | 动能刚好够 |
| 10 rad/s 以下 | ⚠️ 走走停停 | 失速在齿槽峰上 |
| 3 rad/s | ❌ 不可能 | 齿槽需求是维持需求的 15 倍 |

**改善方向：** 换 5~15 Ω 高阻云台电机（Kt 大 → 同样转矩只要 1/4 电流，齿槽相对变小），或做齿槽补偿（按角度查表叠加电流）。
